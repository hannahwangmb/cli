# Impact.com CLI Demo
A simple Java CLI that prints out the name of **impact.com** using the [Picocli](https://picocli.info/) library. 

## Usage

Compile and run:

```bash
javac -cp picocli-4.7.7.jar CompanyCli.java
java -cp ".;picocli-4.7.7.jar" CompanyCli
```

Output:

```
impact.com
```
